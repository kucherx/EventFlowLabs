EventFlow Manager

Усі файли сайту лежать в одній директорії.

Запуск:
1. Запустити start_site.bat
2. Відкрити http://localhost:8080/

Для XAMPP:
1. Скопіювати цю папку в C:\xampp\htdocs\EventFlowSite
2. Запустити Apache
3. Відкрити http://localhost/EventFlowSite/

Сайт не потребує MySQL, бо використовує демо-дані з data.js і localStorage.
